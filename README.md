搜"便宜虚拟主机"的人，预算通常很明确：一个月十几块，甚至几块，能跑起来一个 WordPress 博客、一个企业展示页、或者一个 PHP 小工具就行。

所以真正的问题不是"哪家最便宜"——市面上 5 元、6 元起步的虚拟主机一抓一大把。真正的问题是：**这么低的价格，你拿到手的到底是什么？**

## 便宜虚拟主机的"便宜"，便宜在哪

虚拟主机本质上是一台服务器切给多个人用。厂商把 CPU、内存、带宽、硬盘这些资源按套餐分配，成本摊薄，所以单价能压到云服务器做不到的水平。

代价是：你拿不到完整权限，资源有上限，超限会被限制甚至停机。

雨云的虚拟主机分两条线，差别不在价格，而在"你被共享掉了什么"：

- **EP 面板主机**：用的是 EasyPanel（Kangle 开发的国产面板）。带宽和存储空间独享，CPU 和内存共享。只支持 PHP + MySQL，单个主机限制绑定 5 个域名，只给一个数据库。适合静态站或单个 PHP 站。
- **宝塔面板主机**：基于 LXD 容器，CPU、内存、带宽、空间都独享，预装 LNMP，不限站点数量、不限数据库、不限域名，支持 SSH/SFTP/MySQL 远程连接，可以自己装环境。IP 仍然是共享的，只能用固定端口，除非额外买独立 IP。

一句话概括：EP 是"够用就行"，宝塔是"当小服务器用"。

同一个价位档，宝塔主机给的硬盘和内存明显更多，但你要接受共享 IP 和固定端口这套限制。雨云官方文档里直接建议所有用户优先选宝塔主机，理由是新手老手都好上手——这个建议和价格结构是吻合的。

## 机房怎么选：免备案还是几十毫秒的延迟

低价虚拟主机的机房选择，本质上是在"速度"和"麻烦程度"之间做交换。雨云目前提供三个区域给虚拟主机：

| 区域 | 国内访问延迟（官网参考值） | 备案 | 特点 |
| --- | --- | --- | --- |
| 中国内地节点 | 约 25ms | 需备案 | 三网优化，带高防，国内访问最快 |
| 中国香港二区 | 约 88ms | 免备案 | CN2 三网直连，带宽较小，延迟低 |
| 美国洛杉矶 1 区 | 约 173ms | 免备案 | 国际大带宽 AS4837，适合大流量站点 |

三种情况对应三种人：

- 面向国内用户、有备案域名、在意打开速度——选国内节点。
- 不想折腾备案，网站主要读者在国内——选香港，88ms 的延迟做内容站完全够用。
- 做下载站、图床、资源站这类吃带宽的业务——选美国洛杉矶 1 区。

所有区域的流量都不限，这点在低价主机里比较少见。雨云虚拟主机还默认带 CC 防火墙和 DDoS 自动防御，被打了会自动切防护线路，结束后切回直连，不需要你手动操作。

## 便宜主机最容易踩的坑

雨云论坛和用户文档里被反复提到的问题，基本集中在下面几条。这些坑不难绕开，但不知道就会浪费一个晚上。

**域名要在两个地方都绑一次。** 在宝塔面板里创建站点并绑定域名之后，还得回到雨云虚拟主机管理面板再绑一次，否则域名解析对了也打不开。这是新手最常卡住的一步。

**phpMyAdmin 的端口要手动改。** 共享 IP 的宝塔主机只开放固定端口。没买独立 IP 的话，访问 phpMyAdmin 需要把链接里默认的 888 端口换成雨云面板显示的那个。建议顺手把 phpMyAdmin 升到 5.2、PHP 版本设成 7.4。

**数据库连接地址写 127.0.0.1，端口 3306。** 装 WordPress 的时候，数据库地址填 `127.0.0.1`、端口填 `3306`，不能填面板上显示的那个远程 MySQL 端口。远程连接 Navicat 这类工具时才用面板给的端口，并且要在宝塔安全设置里放行、数据库密码设复杂一点。

**别在宝塔面板里随便改端口或绑域名，也别随便升级宝塔。** 改坏了面板会直接连不上，虽然雨云提供了"修复主机"功能可以救回来，但没必要给自己找事。

**共享 IP 决定了 SSH/SFTP 只适合文件管理。** 拿它做别的用途不现实。要做正经服务、需要完整端口，就老老实实加独立 IP（约 5 元/月，跟主机同周期）或者直接买云服务器。

**低价套餐的资源上限是硬约束。** 这一点不分厂商，几块钱一个月的主机不可能承载突发的访问高峰。资源超限后站点会被暂停，恢复要走流程。买之前把退款政策看清楚——雨云提供七天无理由退订，但这种政策通常有次数限制，别当成无限试用。

## 把月付价再往下压：年付、券和积分

如果确定要长期用，有几层折扣是可以叠加的：

**年付自带 7 折，半年付 8 折，3 个月 9 折。** 这是最直接的一层。EP 入门版 6 元/月的档位，年付折算下来月均不到 4.2 元。

**注册后账户里通常有代金券。** 通过带有优惠通道的注册链接进入，注册完成后一般会直接发一张无门槛代金券，绑定微信和手机号之后还会再补券。具体金额以你账户里实际显示的为准。

**消费返积分，积分能当钱用。** 雨云的返利是积分形式，2000 积分约等于 1 元，可以用来续费、兑换福利，也可以提现。注册即送积分，签到、做任务都能攒。另外消费 1 元之后，返利比例会从 10% 提高到 12%——所以如果你打算买多台机器，一台一台分开买比一次下单更划算。

**1 元试用一天，试用后再买仍算新购。** 雨云云服务器和部分产品支持 1 元试用。试用过再购买不会被系统算成续费，还能用新购折扣券。想先测延迟再决定买哪台的话，这条路比较省心。

**新购 65 折券由邀请方发放。** 雨云的邀请机制下，注册时填的邀请码决定了你的上级，折扣力度较大的新购券需要邀请方主动发放。这不是官网公开活动，能不能拿到取决于你走的是谁的链接，注册后可以在控制台确认自己账户里有哪些券可用。

## 什么样的人适合这种价位的主机

说清楚适用场景，比堆参数有用。

适合：个人博客和 WordPress 小站、企业展示页、PHP 学习环境、需要跑个小工具或接口的开发者、预算有限的学生。这类站点日访问量几百到几千，用 EP 标配或者宝塔标准版就够，没必要上顶配。

不太适合：日 PV 上万的内容站、需要独立 IP 对外提供服务、要跑 Java / Node / Python 环境、需要自定义端口和完整 root 权限的项目。这些需求，虚拟主机再怎么选也满足不了，直接看雨云的云服务器更省事——同样支持 1 元试用和七天无理由退订，可以先试再决定。

## 常见问题

**便宜虚拟主机能备案吗？**
国内节点可以备案，海外（香港、美国）节点免备案但无法备案。反过来说，用国内节点做网站，域名必须先完成备案。

**一个月几块钱的主机真的能用吗？**
能跑，但别指望性能。这个价位的核心价值是"低成本把网站上线"，不是"扛流量"。把预期定在个人博客、小展示站的量级，体验是正常的。

**免费版和低价版应该选哪个？**
免费版数量有限、需要抢，且配置是 1 核 512MB 内存，只能算尝鲜。如果你已经确定要认真做站点，直接上 EP 标配或宝塔标准版，一年下来的差价远小于折腾的时间成本。

**买之前想先测延迟怎么办？**
先花 1 元试用一天，测一下你所在网络到目标机房的真实延迟，比看任何评测都准。

**是选 EP 还是宝塔？**
只跑一个 PHP 站、要便宜、不想维护——EP。要装多个站、要能远程连数据库、以后可能加独立 IP——宝塔。两者差价不大，但能力边界差得不小。

预算在这个区间，与其一家家比价，不如先把"要不要备案"和"用哪个面板"这两件事定下来，剩下的选择其实不多。

## 便宜主机最容易踩的坑

雨云论坛和用户文档里被反复提到的问题，基本集中在下面几条。这些坑不难绕开，但不知道就会浪费一个晚上。

**域名要在两个地方都绑一次。** 在宝塔面板里创建站点并绑定域名之后，还得回到雨云虚拟主机管理面板再绑一次，否则域名解析对了也打不开。这是新手最常卡住的一步。

**phpMyAdmin 的端口要手动改。** 共享 IP 的宝塔主机只开放固定端口。没买独立 IP 的话，访问 phpMyAdmin 需要把链接里默认的 888 端口换成雨云面板显示的那个。建议顺手把 phpMyAdmin 升到 5.2、PHP 版本设成 7.4。

**数据库连接地址写 127.0.0.1，端口 3306。** 装 WordPress 的时候，数据库地址填 `127.0.0.1`、端口填 `3306`，不能填面板上显示的那个远程 MySQL 端口。远程连接 Navicat 这类工具时才用面板给的端口，并且要在宝塔安全设置里放行、数据库密码设复杂一点。

**别在宝塔面板里随便改端口或绑域名，也别随便升级宝塔。** 改坏了面板会直接连不上，虽然雨云提供了"修复主机"功能可以救回来，但没必要给自己找事。

**共享 IP 决定了 SSH/SFTP 只适合文件管理。** 拿它做别的用途不现实。要做正经服务、需要完整端口，就老老实实加独立 IP（约 5 元/月，跟主机同周期）或者直接买云服务器。

**低价套餐的资源上限是硬约束。** 这一点不分厂商，几块钱一个月的主机不可能承载突发的访问高峰。资源超限后站点会被暂停，恢复要走流程。买之前把退款政策看清楚——雨云提供七天无理由退订，但这种政策通常有次数限制，别当成无限试用。

## 常见问题

**便宜虚拟主机能备案吗？**
国内节点可以备案，海外（香港、美国）节点免备案但无法备案。反过来说，用国内节点做网站，域名必须先完成备案。

**一个月几块钱的主机真的能用吗？**
能跑，但别指望性能。这个价位的核心价值是"低成本把网站上线"，不是"扛流量"。把预期定在个人博客、小展示站的量级，体验是正常的。

**免费版和低价版应该选哪个？**
免费版数量有限、需要抢，且配置是 1 核 512MB 内存，只能算尝鲜。如果你已经确定要认真做站点，直接上 EP 标配或宝塔标准版，一年下来的差价远小于折腾的时间成本。

**买之前想先测延迟怎么办？**
先花 1 元试用一天，测一下你所在网络到目标机房的真实延迟，比看任何评测都准。

**是选 EP 还是宝塔？**
只跑一个 PHP 站、要便宜、不想维护——EP。要装多个站、要能远程连数据库、以后可能加独立 IP——宝塔。两者差价不大，但能力边界差得不小。

预算在这个区间，与其一家家比价，不如先把"要不要备案"和"用哪个面板"这两件事定下来，剩下的选择其实不多。
